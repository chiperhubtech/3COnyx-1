🔥 THE ONYX CONSUMER-FIRST OS: REPLIT UX PROMPT (COPY & PASTE)
Act as a Principal UX/UI Architect and Lead Next.js/Tailwind Developer. Execute a total frontend refactor of the 3C ONYX / DealerFlow platform.
⚠️ CRITICAL DIRECTIVE: DO NOT ALTER THE BACKEND. The PostgreSQL database, 7-Agent Mesh, Dependency-Aware State Machine, and external API integrations MUST remain perfectly intact. Your sole objective is to reskin the frontend from a "System Interface" into a "Consumer-First Assistant Experience."
1. THE "UBER + APPLE" UX MANDATE:
 * Zero Overchoice: Limit visible options to a maximum of 3–4 per screen.
 * Remove the Flex: Delete all technical metrics from the main consumer screen (e.g., remove "$ Saved," "AI Agents Active," "Confidence %").
 * De-Jargon the Platform: Replace all internal/technical terminology with warm, friendly, B2C language.
   * Change: "AUTHORIZED PLATFORM ACCESS" → "Welcome"
   * Change: "SOVEREIGN ACCESS KEY" → "Enter phone or email"
   * Change: "F&I Pending" → "We’re finalizing your financing"
   * Change: "DMV Processing" → "We're getting your plates ready"
2. THE NEW HOME SCREEN ARCHITECTURE (The Hub):
 * TOP (Assistant Entry): A clean, welcoming header: "What do you need help with?" followed by 4 large, soft-edged buttons: [ Buy a car ], [ Fix my car ], [ Insurance ], [ Service ].
 * MIDDLE (Active Flow Card): If the user has an active Deal or Task in the backend, display a single, elegant card. Show the Vehicle, a simple Status, a visual Progress Bar, and one massive CTA button: [ Continue ].
 * BOTTOM (Minimal Nav): Strip the navigation bar down to the absolute essentials. Move "Ecosystem," "Settings," and "Alerts" to a secondary, hidden hamburger menu or profile layer.
3. "ASK ONYX" - THE PRIMARY INTERFACE (FAB):
 * Implement a persistent Floating Action Button (FAB) anchored to the bottom right or center: [ Ask ONYX ].
 * Tapping this opens a conversational modal (text or voice input). When a user types "I have a flat tire" or "I want to buy a black Ram 1500", the UI must instantly pass this payload to the backend Intake Agent, which will silently trigger the complex workflows.
4. THE "ONE-STEP FOCUS" RULE:
 * At any moment, the user should see ONE primary action.
 * The user should NEVER have to think: "Where do I go?" or "What do I click next?" The UI must pull the Next_Action from the backend Dependency Engine and serve it to the user on a silver platter.
5. BRANDING & AESTHETICS:
 * Vibe: Calm, fast, helpful, invisible. It should feel like a premium concierge service.
 * Styling: Mobile-first. Use generous whitespace, rounded corners, subtle shadows, and a clean, high-contrast color palette. Ensure interactive elements (buttons) are large enough for effortless thumb-tapping.
FINAL GOAL: Transform the platform into a frictionless experience where the user taps once, the system handles the chaos, and no confusion exists. It must feel like an assistant that just handles everything. Execute the frontend refactor now.
