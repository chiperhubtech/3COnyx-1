THE 7 AGENT SYSTEM (REPLACES STAFF)

Each deal is executed by autonomous agents:

1. SALES AGENT
- Converts text (SMS/chat) into structured deal terms
- Example: "$599/month with 2k down" → parsed deal object

2. DESK MANAGER AGENT
- Replicates dealership desking logic
- Structures payments, terms, lender matching

3. FINANCE AGENT
- Submits deals to lenders (API or browser automation)
- Returns approvals instantly

4. INSURANCE AGENT
- Integrates with InsureMO API (or mock service)
- Binds insurance instantly (eliminates phone calls)

5. INVENTORY AGENT
- Locates vehicles across dealer network
- Executes digital dealer trades (no runner, no paper)

6. LOGISTICS AGENT
- Manages vehicle transport (pickup/delivery tracking)
- Replaces separate transport apps

7. SERVICE + WARRANTY AGENT
- Digitizes repair orders, goodwill, warranty submissions
- Eliminates manual paperwork
